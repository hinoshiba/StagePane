# Governance

StagePane is currently in a founder-maintained pre-release phase. Before the
first external contribution or public commercial release, identify maintainers,
code owners, release approvers, security contacts, conduct contacts, trademark
owner, and continuity/transfer rules.

## Decision principles

1. Protect user consent and screen-content privacy.
2. Tell the truth about being a normal shareable window, not a display.
3. Prefer public platform APIs and a small dependency surface.
4. Keep the free/open core useful and accessible.
5. Record release, license, security, and compatibility evidence.

Two-person review is required for release signing, entitlements, capture data
flows, dependencies, licenses, privacy claims, payments, and trademark policy
once the maintainer team has at least two qualified members.

Apache-2.0 contributions remain under Apache-2.0. A proprietary dual-license
program, copyright assignment, or material governance change requires explicit
public proposal and contributor/legal review; it cannot be inferred from DCO.
