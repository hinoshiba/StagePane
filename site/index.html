Built for calm sharing

「見せたくない」を、
設計で減らす。

共有する内容と操作する場所を分け、プレゼン中の迷いや誤操作を少なくします。

共有用と編集用を、明確に分離

共有Stageには観客向け内容だけを表示し、編集UIは載せません。配置・切り抜き・手書きはWorkspaceのキャンバス、ソースと設定はDocker風のサイドバーで扱います。「共有しない」は技術的な取得防止境界ではないため、会議アプリでは正確なStageウインドウを選び、アプリ全体やディスプレイ全体は共有しません。

一瞬でPrivacy Curtain

⇧⌘H でStageを前面へ移動せずにすぐ覆えます。メッセージは80文字まで。カーテン自体では取得は止まらないため、完全に止めるときは「すべて停止」を使います。

無料で4ソース、Proならアプリ側の件数制限なし

Appleのシステムピッカーで1件ずつ追加し、「ソース」で一時停止・再開・選び直し・確認付き解除を行えます。一時停止はそのストリームを止め、配置・切り抜き・重なり順を保持したままStage、手元用Workspace、Audience PNGでレイヤーを透明にします。再開後は新しい完全なフレームが届いた時点で再表示します。無料版は同時に4件まで、買い切りのStagePane Proにはアプリ側のソース件数制限がありません。実際に利用できる件数はMacの性能とOSの制約に依存します。大きなキャンバスでは自由配置、各レイヤーのボタンから開く切り抜き、ペン、半透明の蛍光ペン、大きさを変えられる部分消去と正確な取り消しを利用できます。切り抜き中は対象レイヤーだけを手元で全面表示して下書きし、「切り抜きを適用」するまで公開Stageは適用済みの範囲を保ちます。キャンセルは下書きを破棄します。切り抜きは表示マスクであり、ソースの取得中、ScreenCaptureKitは選択したソース全体を扱います。適用済みの枠は、共有終了後に「選び直す」を待つレイヤーを含めてアプリ内メモリだけに保持し、そのレイヤーの解除、確認後のすべて停止、またはStagePane終了時に破棄します。手書き中は観客側のポインターを自動で隠し、配置へ戻ると選択中の設定を復元します。各選択はその共有対象と取得セッションだけを許可し、別途広範な画面収録許可は求めません。共有元アプリへの入力転送や、アクセシビリティ・入力監視の権限要求もありません。

きれいな1枚のスクリーンショット

観客側Stageを16:9（1920×1080）、4:3（1440×1080）、9:16（1080×1920）、1:1（1080×1080）のPNGとして明示的にコピーまたは保存できます。現在の共有内容またはカーテン、手書き、ロゴ、有効な場合はセーフエリア、表示中の場合はポインターを含み、Workspaceの編集UIは含みません。

発表に合わせた見え方

Aurora、Midnight、Paper、Studioのテーマに加え、通常・レーザーポインター・非表示を選べます。レーザーポインターは色・サイズ・発光を調整でき、最前面ソースだけに表示します。半透明のStagePaneロゴは待機画面、共有内容、カーテンの右下に表示され、買い切りのStagePane Proなら設定から非表示にできます。

ローカルで完結

録画、外部送信、アカウント、広告、解析SDKはありません。フレームは自動保存せず、明示的な「画像をコピー」「PNGを保存」だけが、きれいなStage画像をローカルへ1枚出力します。

Real interface

機能と安心を、
実画面で確認。

以下はStagePane自身が合成データだけで描画した画面です。Workspaceを手元に置き、会議アプリでは正確なStageウインドウだけを共有します。

How it works

Stageの準備は、
4つのステップ。

仮想ディスプレイや別のデスクトップは作りません。会議アプリから普通のウインドウとして選びます。

正確なウインドウ名を確認

会議アプリでは「StagePane Stage」を選びます。「共有しない」はWorkspaceを技術的に除外する仕組みではなく、アプリ全体やディスプレイ全体の共有では映る可能性があります。macOS 15以降の「共有先をStageへ切替」は、対応する実行中の共有セッションへ切り替えを依頼する機能であり、すべての会議アプリで共有を開始・操作できるものではありません。

  1. 01

    StagePaneを開く

    StagePaneは、きれいな共有Stageと、キャンバス・ソース・設定をサイドバーにまとめた手元用Workspaceの2画面です。

  2. 02

    見せるものを追加

    「ソースを追加」でウインドウ・アプリ・画面から1件を、その取得セッション用に許可します。アプリを選ぶと、そのアプリが持つ複数のウインドウが含まれる場合があります。範囲を狭くする場合は1つのウインドウを選びます。無料版は同時に4件まで追加でき、買い切りのStagePane Proにはアプリ側の件数制限がありません。実際に利用できる件数はMacの性能とOSの制約に依存します。

  3. 03

    配置してStageを共有

    手元のWorkspaceで移動・サイズ変更・手書きを行い、会議アプリでは正確な「StagePane Stage」ウインドウを選んでカーテンを開きます。

  4. 04

    終わったら完全に停止

    「すべて停止」で全ストリームを終了し、配置と切り抜きを保持している再接続待ちを含む、すべてのレイヤーを削除します。カーテンだけでは取得は止まりません。

Privacy by design

画面処理は、
あなたのMacの中だけ。

StagePaneは選んだ内容をメモリ上で表示し、自動保存せず破棄します。明示的な「画像をコピー」「PNGを保存」だけが、きれいなStage画像をローカルへ1枚出力します。実際の配信は会議アプリ側が行います。

1選んだ内容選択ごとに許可
→
2メモリ内の構図録画・解析なし
→
3Stage + Workspace同じフレームを並列表示

取得・保存

  • 画面フレームを録画・自動保存しません
  • 「画像をコピー」はきれいなPNGを1枚だけクリップボードへ置き、「PNGを保存」は選んだ場所だけへ書き込みます。キャンセル時は何も保存しません
  • 音声やマイクを取得しません
  • OCRやAI解析はありません

通信・追跡

  • 画面や利用状況をStagePaneから外部送信しません
  • アカウント、広告、解析、テレメトリーはありません
  • 課金の商品情報と購入状態だけをAppleのStoreKitが処理します

設定・権限

  • テーマ、ポインター、ロゴ表示などの設定だけをMac上のローカル設定に保存します
  • ソース名、ウインドウ名、ファイル名、会議情報は保存しません
  • 常設の「アクセス権限」では、Appleの選択画面が共有対象ごとにセッション許可することを説明し、別途広範な画面収録許可は求めません
Privacy Curtainは「取得停止」ではありません。

カーテンが隠すのは公開Stageだけです。個別の「一時停止」はそのストリームを止め、配置・切り抜き・重なり順を保ったままレイヤーを透明にします。再開後は新しい完全なフレームから再表示します。「解除」は1レイヤーの映像と状態を削除し、「すべて停止」は全ストリームと全レイヤーを削除します。

Security

公開Issueに秘密情報を載せないでください。

脆弱性の疑いは公開Issueへ投稿せず、件名に「StagePane Security」と記載して support@hinoshiba.com へ送信してください。1.0未満では、最新の公開リリースをセキュリティ対応の対象とします。

Support

困ったときの、
確認ポイント。

一般的な使い方や再現可能な不具合はGitHub Issuesで受け付けます。非公開の連絡やその他のお問い合わせは support@hinoshiba.com へお送りください。

GitHub Issueを作成
01

ウインドウを見失った

Stage Workspaceまたは共有Stageはメニューバーから再表示できます。⇧⌘H はカーテン、⇧⌘P は「ソースを追加」です。

02

取得がうまく戻らない

解除されたレイヤーの「選び直す」から同じ配置と切り抜きへ再接続できます。共有Stageを閉じてもレイヤーと取得はWorkspaceに残るため、完全に終了する場合は「すべて停止」を使ってください。

03

Issueに載せてよいもの

macOS・StagePaneのバージョン、合成データで再現する手順、期待した結果と実際の結果を共有してください。

!

載せてはいけないもの

実際の画面フレーム、私的なウインドウ名、会議URL、トークン、TCCデータベース、未編集の診断情報は投稿しないでください。

Build from source

自分のMacで、
ソースから試す。

macOS 14以降とXcode 16以降を用意し、リポジトリをcloneしてください。Apple SiliconとIntelの両方を対象にしています。

公式版はMac App Storeで配信中です。 ./build.sh の成果物はStore版と同じApp Sandboxと配置・切り抜き・手書き機能を使いますが、開発用のad-hoc署名・未公証ビルドであり、公式バイナリや配布用成果物ではありません。

リポジトリを開く使い方へ戻る ↑
Terminal
$ git clone https://github.com/
  hinoshiba/StagePane.git
$ cd StagePane
$ ./build.sh
$ open dist/StagePane.app
