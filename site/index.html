How it works

Stageの準備は、
4つのステップ。

仮想ディスプレイや別のデスクトップは作りません。いつもの会議アプリから、普通のウインドウとして選べます。

  1. 01

    StagePaneを開く

    StageとControl Room、役割の異なる2つのウインドウが現れます。

  2. 02

    見せるソースを選ぶ

    Appleのシステムピッカーで、ウインドウ・アプリ・画面を許可します。

  3. 03

    Stageを共有する

    ZoomやTeamsなどで「StagePane Stage」を共有対象に選びます。

  4. 04

    終わったら完全に停止

    Control Roomからキャプチャを停止し、表示していたフレームを破棄します。

Open source

自分のMacで、
ソースから試せます。

Xcode 16以降を用意して、リポジトリをcloneしてください。現在公開しているのはソースコードです。 通常のビルドは開発用・未公証のため、再配布には使えません。

リポジトリを開く 使い方を見る →
Terminal 
$ git clone https://github.com/
  hinoshiba/StagePane.git
$ cd StagePane
$ ./build.sh
$ open dist/StagePane.app
