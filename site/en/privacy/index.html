At a glance

StagePane does not collect personal data.

StagePane has no account, advertising, analytics, telemetry, or third-party runtime SDK, and it makes no network requests. The sandboxed Mac App Store build also has no network client entitlement.

  • No recordingChosen screen frames are processed in memory only for display.
  • No automatic savingOne Stage PNG is exported only when you explicitly choose Copy or Save Audience Image.
  • No uploadStagePane does not send your screen or usage to the publisher or any third party.

Screen content

StagePane accesses screen content only after you open Apple's system content-sharing picker and explicitly choose one window, application, or display. You can repeat this for up to four sources that can be paused and removed independently.

Chosen frames appear in “StagePane Stage,” the clean window intended for sharing, and the Canvas in “Stage Workspace.” Sources, Stage Settings, Appearance, Permissions, Privacy, and About are available from the Workspace sidebar.

Each choice grants access only to that selected content for that capture session. StagePane does not request separate, broad Screen Recording access. Canceling the picker adds nothing. Removing a source or choosing Stop All ends the corresponding streams and discards their displayed frames.

StagePane does not:

  • record or encode selected frames;
  • write them to disk, logs, the clipboard, or a database, except for the explicit one-shot PNG export described below;
  • perform OCR, object recognition, or AI processing;
  • transmit them to StagePane, its publisher, or any third party; or
  • capture system audio or microphone audio.

Laser pointer

When you choose the Laser pointer style, StagePane reads only the current pointer position needed to place one dot over the frontmost Stage source. If that source is paused, no dot appears and StagePane does not fall back to a source behind it. StagePane does not retain pointer history or write coordinates to disk; each sampled position is continuously discarded and cleared when capture stops or the source changes. Laser mode itself does not install an event tap or request Accessibility or Input Monitoring permission.

Preview modes and build variants

Mac App Store

Arrange and Draw

This sandboxed build omits Press Buttons and every cross-application Accessibility path. It does not request Accessibility or Input Monitoring permission.

Local development

Arrange, Draw, and limited Press Buttons

An unsandboxed build compiled locally from source may additionally provide Press Buttons on macOS 15.2 or later. No official direct-distribution build is currently offered.

In a local development build, selecting Press Buttons without access does not itself trigger a system prompt. StagePane asks macOS for Accessibility permission only after you explicitly choose Continue Setup on the Accessibility card in the persistent Permissions view.

Press Buttons accepts a point only when the selected source is exactly one on-screen window, the point comes from a fresh lifecycle-fenced frame shown in Workspace, and an application-scoped Accessibility hit test finds a pressable control belonging to that same window. StagePane then asks the control to perform its supported Press action. It does not synthesize arbitrary mouse events, move the physical pointer, activate or focus the source app, read keyboard input, forward keys or drags, enumerate unrelated windows, log actions, or retain coordinates.

Draw, Pause, and Curtain behavior

Draw keeps a bounded set of normalized vector strokes in memory and renders the same ink in the private Workspace and public Stage. It does not automatically write, upload, or analyze ink. An explicit Audience Stage screenshot includes visible ink as rasterized pixels. Stop All or removal of the final source clears the in-memory drawing.

During normal playback, frames are discarded as display advances. Pausing one source stops its stream but intentionally retains its last displayed frame in local memory. Resume restarts that source, while Remove flushes its retained frame. Stop All does this for every source.

Privacy Curtain is not Stop Capture.

The Curtain visually covers only the public Stage. It does not pause active sources, and the private Workspace remains visible so you can prepare the composition.

The “Keep Private” label on Stage Workspace is workflow guidance, not a technical privacy boundary. Sharing the StagePane application or a full display can expose that window. When it must stay hidden, choose the exact “StagePane Stage” window in your meeting app.

User-initiated screenshots

StagePane does not take screenshots on a timer, in the background, at launch, or in response to capture changes. It creates one lossless PNG of the clean Audience Stage only when you choose Copy Audience Image or Save Audience Image… in Stage Workspace.

The PNG uses the selected Stage pixel dimensions and includes what the audience Stage currently shows: shared content or Curtain, ink, mark, safe-area guide, and pointer. It excludes Workspace navigation and controls, title-bar chrome, and unrelated application windows.

The image is composed locally from the latest pixels already approved through Apple's content-sharing picker and StagePane's own artwork. This path does not enumerate unrelated windows, request new screen permission, record video, or use the network.

Copy places the PNG on the macOS general pasteboard. Other local applications and clipboard managers may access it according to their own behavior. Save opens the macOS save panel and writes only to the location you select; canceling writes nothing. After the copy or write finishes, StagePane keeps no separate screenshot history or screenshot file of its own.

Settings stored on your device

StagePane stores interface preferences such as aspect preset, theme, pointer style, color, size and glow, drawing tool/color/ink width/eraser size, mark and safe-area visibility, Curtain message, and window behavior in local UserDefaults on your Mac.

It does not persist your chosen source, window title, application name, screenshot history, chosen screenshot path, or meeting information. Standard window-frame preferences may include the positions and sizes of the Stage and Workspace windows, but not their pixels. A PNG created through Save is your chosen local file, not an app preference or hidden retained copy.

Source titles may appear transiently in the in-memory source list while capture is active. Dragged positions and sizes are session-only in this version. You can remove preferences by deleting the app's local container or using available macOS app-data controls.

Permissions

The persistent Permissions view explains that Apple's system picker grants screen-sharing access per selection and per capture session. The normal Add Source flow does not present a global Screen Recording status, request separate broad Screen Recording access, or require a System Settings step. Removing a source or choosing Stop All ends its session-scoped access. StagePane remains usable as a holding share window before you select a source.

The Mac App Store build requests no Accessibility or Input Monitoring permission, and its Permissions view hides the Accessibility card. In a local development build, Accessibility permission for Press Buttons is separate from picker-scoped screen sharing and is requested only from the card's explicit Continue Setup action. No build variant requests Input Monitoring.

Network and third parties

StagePane makes no network requests, including for screenshots you copy or save. The meeting app that shares StagePane Stage is separate software. Its transmission, recording, account, and data practices are governed by that provider's terms and privacy policy.

macOS and Apple frameworks are part of the operating system. Their behavior is governed by Apple's terms and privacy information.

Retention, disclosure, sale, and tracking

Because StagePane does not collect screen content or personal data, it has no server-side retention, disclosure, sale, cross-context behavioral advertising, or tracking process. A screenshot you explicitly copy or save exists only in the local pasteboard or chosen file location and is not retained by the publisher.

The app privacy manifest declares that tracking is false and collected data types are empty. StagePane is a general productivity utility and is not directed to children.

Changes to this policy

This policy may be updated if StagePane's features or data practices change. The updated policy will be published with a revised effective date. Material changes will be communicated through an appropriate product or project channel.
