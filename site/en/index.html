Clearly separate sharing from control

Put only audience content in the chrome-free Stage. Arrange and draw in the large private Workspace; manage sources and settings in Control Room. “Keep Private” is guidance, not a capture boundary, so verify the title and share the exact Stage window—not the full display or app.

CONTROL

Privacy Curtain in an instant

Cover the Stage with ⇧⌘H without bringing its window to the front, and show a message of up to 80 characters. The Curtain itself does not pause capture; use Stop All to end it.

Arrange and draw with up to four sources

Add sources one at a time with Apple's system picker, manage them in Control Room, then arrange and draw on the large Workspace. Each choice authorizes only that shared content for its capture session; StagePane does not request separate broad Screen Recording access. The Mac App Store build includes Arrange and memory-only Draw, but no Control mode or Accessibility card. Only the unsandboxed local development build on macOS 15.2+ can add narrowly scoped Control; after you explicitly choose Continue Setup in Permissions, it can perform a supported Press action inside the exact selected window. No direct-distribution build is currently offered.

Clean one-shot screenshots

Explicitly copy or save a PNG of the Audience Stage at 16:9 (1920×1080), 4:3 (1440×1080), 9:16 (1080×1920), or 1:1 (1080×1080). It includes the current Curtain, ink, mark, and pointer—never private Workspace chrome.

A view that fits your presentation

Choose Aurora, Midnight, Paper, or Studio, plus a system, laser, or hidden pointer. Adjust the laser pointer's color, size, and glow; it appears only on the frontmost source. A translucent StagePane mark is shown by default in the lower-right of the holding screen, shared content, and the Curtain, and can be disabled.

Local by construction

There is no recorder, upload path, account, advertising, or analytics SDK. Frames are not saved automatically; only your explicit Copy Image or Save PNG action exports one clean Stage image locally.

How it works

Prepare the Stage
in four steps.

StagePane does not create a virtual display or alternate desktop. Select it in your meeting app as an ordinary window.

Check the exact window title

Select “StagePane Stage” in your meeting app. “Keep Private” does not technically exclude Workspace or Control Room; sharing the app or full display can expose them.

  1. 01

    Open StagePane

    The clean Share Stage, large private Workspace, and Control Room have distinct roles. Control Room has no live editor.

  2. 02

    Add what to show

    Choose Add Source and approve exactly one window, app, or display for that capture session. No separate broad Screen Recording permission is needed; repeat for up to four independent sources.

  3. 03

    Arrange and share the Stage

    Move, resize, or draw on the private Workspace, then select the exact “StagePane Stage” window in your meeting app and reveal the Curtain.

  4. 04

    Stop completely when finished

    Use Stop All to end every stream and discard held frames. The Curtain alone does not stop capture.

Privacy by design

Screen processing stays
on your Mac.

StagePane displays chosen content from memory and discards it without automatic saving. Only an explicit Copy Image or Save PNG action exports one clean Stage image locally. The meeting app performs the actual transmission.

Capture and storage

  • Screen frames are never recorded or saved automatically
  • Explicit Copy Image places one clean PNG on the clipboard; Save PNG writes only to your chosen location, and cancel writes nothing
  • System audio and microphone input are not captured
  • There is no OCR or AI analysis

Network and tracking

  • StagePane does not send your screen or usage over the network
  • There are no accounts, ads, analytics, or telemetry
  • No third-party runtime SDK is bundled

Settings and permissions

  • Only preferences such as theme, pointer appearance, and mark visibility are stored in the macOS sandbox
  • Source names, window titles, file names, and meeting information are not saved
  • The persistent Permissions view explains that Apple's picker grants session access per shared selection; StagePane requests no separate broad Screen Recording access
  • The Mac App Store build hides the Accessibility card. Only the local development build requests Control access after you explicitly choose Continue Setup
Privacy Curtain is not “Stop Capture.”

The Curtain hides only the public Stage. Per-source Pause stops that stream but keeps its last frame in memory. Use Remove or Stop All to discard held frames and end capture completely.

Security

Do not put sensitive information in a public issue.

Do not post suspected vulnerabilities in a public issue. Email support@hinoshiba.com with “StagePane Security” in the subject. Before 1.0, the latest published release is the only version eligible for security fixes.

Support

What to check
when something goes wrong.

General usage questions and reproducible defects are accepted through GitHub Issues. For private or other inquiries, email support@hinoshiba.com.

Create a GitHub issue
01

I lost a window

Restore Control Room, Stage Workspace, or the Share Stage from the menu bar. ⇧⌘H toggles the Curtain; ⇧⌘P opens Add Source.

02

Capture did not recover

Use Stop All to reset capture, then add the sources again. Closing the Stage also stops capture.

03

What to include in an issue

Share the macOS and StagePane versions, steps that reproduce the problem with synthetic data, the expected result, and the actual result.

!

What never to include

Do not post real screen frames, private window titles, meeting URLs, tokens, TCC databases, or unredacted diagnostics.

Build from source

Try it from source
on your Mac.

Install macOS 14 or later and Xcode 16 or later, then clone the repository. StagePane targets both Apple Silicon and Intel Macs.

Only the source code is currently published. The output of ./build.sh is an ad-hoc-signed, unnotarized development build—not an official binary or distributable artifact.
