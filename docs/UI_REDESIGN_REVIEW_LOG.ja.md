## 設定の追加整理（2026年10月14日）

利用者からの「権限を必要時のポップアップへ」「プライバシーをAboutへ」という追加提案に対応した。3担当で許可モデル・操作・視覚を独立して確認した。

### 仕様と実装

- アプリ設定は「一般」「このアプリについて」の2項目。Aboutにプライバシー要約、ポリシーへのリンク、開閉式の「プライバシーとデータ」を統合。AppメニューのAboutも同じ画面へ接続した。
- 「画面共有について」はAbout・Stageメニュー・ステータスメニューから独立ウインドウへ。説明を開くだけでmacOSの許可やソース追加を開始しない。追加ボタンを押したときだけ案内を閉じ、既存の追加／Pro条件へ進む。
- 起動時の包括権限チェックは追加しない。SCContentSharingPickerは選んだ対象へのアクセスをセッション中に許可し、別途の包括的な画面収録許可は不要である。未選択・未取得を「権限不足」と扱わない。[Appleの説明](https://developer.apple.com/videos/play/wwdc2023/10053/)
- Pickerの開始失敗と現行世代の取得開始失敗だけを専用イベントで通知し、本文をスクロールできる独立ウインドウへ表示。原因を権限不足と断定せず、既存対象の選び直し手順を示す。閉じる／Escapeと説明へのボタンを固定した。
- 古い世代、無効になった選択要求、削除済み対象、停止・出力抑制中の開始失敗を除外。キャンセル、共有終了、Hide／Stop／後処理失敗を新しいポップアップへ流さない。既存の取得終了・レイヤー保持・再試行処理は維持した。
